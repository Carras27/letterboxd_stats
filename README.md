# letterboxd_stats
A partir de las tablas de datos (.csv) de una cuenta de letterboxd obtenidos en letterboxd.com/user/exportdata/, generar gráficos de distintas estadísticas.

Una vez descargado, subir uno entre: diary.csv, ratings.csv y wathced.csv para visualizar gráficos con estadísticas de tu cuenta de Letterboxd.
